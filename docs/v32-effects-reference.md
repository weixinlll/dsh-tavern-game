# 固定包效果与机制参考 · 0.8.1

两个包：人类对决；玄幻 / 西幻 / 仙侠。60 个真实状态、80 个固定模式，按两包各16个题材生成2560个命名预设，不是2560套独立算法。另有16个可叠加的固定机制。每方最多3人：1人前场、2人后备；每人基础攻击加最多3招，换人占行动。

## 可组合机制

| 标签 | 执行语义 |
| --- | --- |
| first | 先手等级2，优先于普通招式；同级比较速度 |
| critical | 命中时必定暴击，伤害×1.5；抗暴可抵消 |
| sureHit | 跳过命中检定；不绕过控制、招架和护盾 |
| multiHit | 分为3段伤害，共享一次伤害总预算；不获得3倍总伤害 |
| shieldPierce | 穿过普通护盾；不等于穿过招架或无敌 |
| armorPierce | 本次忽略65%防御 |
| execute | 目标低于30%生命时伤害提高25%，仍受单招上限限制 |
| recoil | 出招后自身损失8%最大生命 |
| highCrit | 命中时有40%概率暴击，伤害×1.5 |
| drain | 恢复实际伤害的18%，受治疗预算限制 |
| resourceDrain | 命中后最多夺取15资源，自身最多获得8 |
| cleanseSelf | 出招后清除自身最多2个负面状态 |
| dispelTarget | 命中后驱散目标最多2个增益 |
| healSelf | 出招后恢复10%最大生命，受治疗预算限制 |
| counter | 出招后获得2次行动的反击姿态 |
| shieldSelf | 出招后获得16%最大生命的护盾 |

例如：技能描述“必定先攻、必中、必定暴击、三段攻击、中毒、麻痹、吸血”可编译成多个机制和两个异常，而不是只留下先手。机制只接受白名单，不执行模型公式。主要效果之外最多附加两种异常；过多异常会标明裁剪。

## 资料与编译

一次按钮保留 MVU 原数值。技能仅有名字时，用已配置后台模型补一次短说明，和原文技能匹配后编译，不新增队友和技能。不具备直接 MVU 时一次提取队友。两条路线不会相继请求模型。同一版本与技能来源复用说明。模型返回非法或无法确认的效果会提示，不声称支持任意世界机制。

原始描述最多保留160字，但完整识别后的机制以枚举保存，长描述截取不会抹掉已编译机制。生成的效果说明不重复落入每个存档，读取时按白名单恢复。

## 平衡边界

先手等级更高者先行动，同级比较速度；控制仍可能阻止行动。必中跳过命中检定，仍能被招架；必暴倍率1.5，抗暴去掉加成。连击固定三段，共享一次伤害预算；单体总基准上限27%目标生命，群攻最多3个目标、单目标11%。额外机制会提高消耗/冷却，有次数上限。

治疗共享每方初始总生命55%的整场预算，复苏全场一次，不屈每人一次。召援每方最多一个、三回合，不占参战者槽。反击和荆棘不递归，舍身不能用自己的盾抵消。第13回合加压力，第24回合按生命比例裁定。每动作最多36事件，日志最多100条，接近公开存档上限会裁去旧日志。
