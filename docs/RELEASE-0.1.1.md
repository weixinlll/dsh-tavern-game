# DSH Tavern Game 0.1.1

0.1.1 为角色和技能加入属性与威力数据，扩充默认外观和战斗场景，并改进插件更新的校验、备份与回滚。

- **属性与威力：** 新增 12 种技能属性。角色可有 1—2 种属性；攻击技能威力为 20—140，治疗和辅助技能为 0。AI 在生成角色时一次返回属性与技能威力，手动编辑器保留并允许修改这些字段。克制倍率为 2，抵抗为 0.5；双属性倍率相乘后限制在 0.25—4，同属性技能加成 1.2。
- **默认外观：** 新增蝎子、熊、狮子、蜥蜴、金甲棍武者、长杖贤者六套动作图集，使内置默认外观达到 60 套。角色生成会在同一次请求中选定外观；发色、服装和动物毛色可有更广的安全随机变化。
- **战斗场景：** 新增云海天宫、极光冰城、熔火圣殿三张背景，内置背景总数达到 5 张。
- **更新与恢复：** 发布包使用覆盖全部运行文件的 SHA-256 清单。更新器先在暂存目录校验文件，再切换插件目录；更新前保存经校验的运行文件备份，发布失败会恢复原目录，并支持从有效备份回滚。

安装地址：<https://github.com/weixinlll/dsh-tavern-game>。更新后重启 DSH 以加载宿主侧代码。
