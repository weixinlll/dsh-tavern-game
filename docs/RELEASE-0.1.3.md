# DSH Tavern Game 0.1.3

改进剧情进入战斗的流程，并让战场背景真正铺满整个窗口。

- **全屏战场：** 修复操作区两侧的黑带，背景连续铺到底部；操作台浮动显示，角色和生命条自动避让。
- **紧凑操作区：** 桌面选招区约242像素高，可手动收起；技能常驻，收起后保留指令和目标。长背包单独滚动，确认按钮保持可见。
- **点击进入：** 正文结算后显示一个战斗入口，点击才打开场景；准备过程可取消，支持继续原回合和查看战果。
- **验证：** 216项自动测试及多尺寸真实浏览器隔离流程通过，覆盖三对三、六人队伍、导入资源、倍速、整轮确认和战果回填。

安装地址：<https://github.com/weixinlll/dsh-tavern-game>。更新后重启 DSH；本机已有旧0.1.3测试版时，请重新下载安装本次0.1.3。
